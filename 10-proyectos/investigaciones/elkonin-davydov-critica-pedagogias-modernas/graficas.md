## 3. Efecto de la guía frente al descubrimiento (síntesis de meta-análisis)

```
Nivel de guía          Efecto típico en novatos
──────────────────────────────────────────
Minimal / unguided     │██████████████████  negativo / nulo
                       │
Guided / explicit      │██████████████████████████  positivo medio-grande
```

*Síntesis a partir de Kirschner, Sweller & Clark (2006) y meta-análisis posteriores (Alfieri et al., Lazonder & Harmsen).  
La instrucción mínimamente guiada es, en promedio, inferior para novatos.*

## 4. Expertise-reversal effect (esquema conceptual)

```
Eficacia de la guía alta
        ┌──────────────────────────────────┐
        │  Alta  │█████████████████████████████  │  Novatos
        │        │                                      │
        │  Baja  │█████████████████████████████  │  Expertos
        └──────────────────────────────────┘
                 Novatos →→→→→→→→→ Expertos
```

*La guía alta es esencial para novatos; se vuelve redundante o perjudicial cuando el alumno ya posee esquemas sólidos (expertise-reversal).  
Fuente conceptual: Kalyuga, Sweller y colaboradores.*

## 5. Dos caminos pedagógicos (tesis central)

```
CAMINO EMPIRISTA (concreto → abstracto)          CAMINO ELKONIN-DAVYDOV (abstracto → concreto)

  Experiencia concreta inmediata                    Célula germinal / estructura abstracta
           ↓                                                    ↓
  Inducción / descubrimiento                        Modelado y mediación
           ↓                                                    ↓
  Generalización (lenta, frágil)                    Concreción y aplicación
           ↓                                                    ↓
  Riesgo: «traductor perpetuo»                      Resultado: pensamiento teórico
            de lo particular                                    que desciende a lo particular
```

*El segundo camino coloca al alumno sobre hombros de gigantes. El primero lo condena a reinventar la rueda.*

## 6. Paralelismo moral: Values Clarification vs Character Education

|  | Values Clarification | Character Education / Virtue |
|--|----------------------|-----------------------------|
| **Punto de partida** | Preferencias del alumno | Principios / virtudes culturales |
| **Rol del maestro** | Facilitador neutral | Mediador y modelo |
| **Riesgo** | Relativismo situacional | Formalismo si falta vida |
| **Evidencia de eficacia** | Baja (Leming 1981 y posteriores) | Superior en formación de carácter |
| **Paralelismo cognitivo** | Discovery mínimamente guiado | Elkonin-Davydov / instrucción guiada |

*Ambos dominios (matemáticas y ética) convergen: ofrecer primero las abstracciones potentes mediadas, no partir de lo meramente personal o concreto.*

---

## 7. Condición cognitiva de la moral principiada (Kohlberg)

```
Nivel moral                  Requisito cognitivo
──────────────────────────────────────────
Preconvencional              Consecuencias inmediatas
Convencional                 Normas del grupo
Postconvencional             Operaciones formales (abstracción)
                             ← condición necesaria
```

*Sin capacidad de abstracción formal, el juicio moral tiende a quedarse en lo particular y situacional.*

## 8. Síntesis visual de la tesis final

```
                    ABSTRACCIONES CULTURALES POTENTES
                    (estructuras matemáticas / principios éticos)
                                 │
                                 │  mediación viva
                                 ▼
                    INTERNALIZACIÓN COMO HERRAMIENTAS
                                 │
                                 │  descenso
                                 ▼
                    CONCRECIÓN + INDAGACIÓN + AUTONOMÍA
                    (cuando el alumno ya posee las herramientas)
```

**Conclusión visual:**  
Invertir este orden de forma dominante y prematura deja al alumno como traductor perpetuo de su experiencia particular. En matemáticas limita el razonamiento; en ética empuja al relativismo situacional.
