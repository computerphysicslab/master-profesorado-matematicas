## Secuencia sugerida

1. **Sin pantalla (5 min):** lista $8,9,7,10,8,12,9,11,8,45$. Estimar media y mediana a ojo.  
2. **Afirmación:** «La media siempre es el mejor resumen.» Voto rápido verdadero/falso.  
3. **Notebook:** ejecutar resumen; comparar *con* y *sin* el 45.  
4. **Gráfica:** localizar media y mediana; comentar el atípico.  
5. **Cierre (5 min):** qué número usaría el profesor para planificar; norma de no etiquetar al «45».

---

## Mediación

| Bloqueo | Pregunta |
|---------|----------|
| Confunde media y mediana | «Si ordenas los tiempos, ¿cuál queda en el centro?» |
| Quiere «eliminar siempre» el atípico | «¿Y si el 45 es un dato real de bloqueo? ¿Qué información perderías?» |
| Solo mira el número | «¿Para *qué decisión* de aula sirve cada resumen?» |
