# Artículos y recursos breves

Espacio para artículos, capítulos sueltos y guías cortas de acceso abierto.

## Cómo añadir entradas

Para cada recurso, indicar:

1. Título y autores  
2. Enlace al PDF o al repositorio GitHub  
3. Licencia  
4. Asignatura(s) del máster a las que aporta  

Ejemplo de entrada:

```markdown
### Título del artículo
- Autores: ...
- PDF / repo: https://...
- Licencia: CC BY 4.0
- Útil para: Diseño de actividades, Innovación educativa
```

## Fuentes recomendadas para buscar más

- [AIM Open Textbook Initiative](https://textbooks.aimath.org/)
- [Open Textbook Library](https://open.umn.edu/opentextbooks/)
