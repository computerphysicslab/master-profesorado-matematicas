# Rutas de lectura

## Ruta 1 — Psicología del aprendizaje

Piaget → Vygotsky → Bruner → Ausubel → Bandura → Sweller → Dweck

## Ruta 2 — Historia de la pedagogía

Sócrates → Rousseau → Pestalozzi → Dewey → Montessori → Freinet → Freire

## Ruta 3 — Educación Matemática

Pólya → Freudenthal → Brousseau → Chevallard → Vergnaud → Duval → Schoenfeld → Artigue

## Ruta 4 — Profesor como profesional reflexivo

Tyler → Stenhouse → Shulman → Schön → Elliott

## Ruta 5 — Escuela y sociedad

Durkheim → Weber → Bourdieu → Bernstein → Foucault → Goffman

## Ruta 6 — Matemáticas + programación + tecnología

Papert → Kay → Resnick → Turing → Knuth

## Ruta 7 — Preparación conceptual del TFM

1. Identificar un problema educativo.
2. Localizar el concepto teórico asociado.
3. Identificar autores y marcos rivales.
4. Revisar investigación reciente.
5. Diseñar una intervención o investigación.
6. Evaluar evidencias y limitaciones.
