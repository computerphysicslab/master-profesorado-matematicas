# Recursos en GitHub para el Máster de Profesorado de ESO – Matemáticas

Esta página recopila **repositorios de GitHub** útiles para el Máster de Profesorado (especialidad Matemáticas): listas curadas, materiales didácticos, libros abiertos y herramientas interactivas.

> **Licencias (aviso):** Se priorizan recursos con licencia abierta o permisiva, pero **no todos** son «código abierto» en sentido estricto.
> - Algunos usan **CC BY-NC** (p. ej. visualproofs): uso no comercial con atribución; no es licencia OSI.
> - **GeoGebra** tiene términos propios (software libre con restricciones de marca y de ciertos recursos de la plataforma).
> - Verifica siempre el archivo `LICENSE` del repositorio y la fecha de consulta antes de reutilizar.
>
> | Recurso (ejemplo) | Licencia reportada | Notas |
> |-------------------|--------------------|-------|
> | Listas *awesome-math* | Suele ser CC0 / similar | Solo la lista, no el contenido enlazado |
> | fresdu/DocMath | MIT (según README) | Confirmar `LICENSE` en el repo |
> | MMLand/TFM-2025-MAES | GPL-3.0 | Código y materiales del TFM |
> | visualproofs | CC BY-NC 4.0 | No comercial |
> | GeoGebra (plataforma / forks) | Términos GeoGebra + forks | No asumir solo «CC BY-SA» |

## 1. Listas curadas (*awesome lists*)

- **[rossant/awesome-math](https://github.com/rossant/awesome-math)** — lista de referencia (libros, cursos, herramientas).
- **[bryanwills/awesome-math](https://github.com/bryanwills/awesome-math)** — énfasis en enseñanza y resolución de problemas.
- **[brandonhimpfen/awesome-mathematics](https://github.com/brandonhimpfen/awesome-mathematics)** — teoría, pruebas, datos y recursos educativos.
- **[ossu/math](https://github.com/ossu/math)** — currículo de autoaprendizaje tipo grado.
- **[FreeMathBooks/free-math-books-collection](https://github.com/FreeMathBooks/free-math-books-collection)** — libros gratuitos por áreas.

## 2. Materiales didácticos para ESO y Bachillerato

- **[fresdu/DocMath](https://github.com/fresdu/DocMath)** — sistema modular (metodología Craig Barton); ejercicios diferenciados. Licencia reportada: MIT (verificar).
- **[ilarrosa/GeoGebra](https://github.com/ilarrosa/GeoGebra)** — construcciones para ESO/Bachillerato.
- **[MMLand/TFM-2025-MAES](https://github.com/MMLand/TFM-2025-MAES)** — ejemplo de TFM con materiales; **GPL-3.0**.

## 3. Software y plataformas

- **GeoGebra** — [https://www.geogebra.org/](https://www.geogebra.org/) y repositorios comunitarios. Consultar términos de uso; no asumir solo CC BY-SA.
- **[visualproofs](https://github.com/visualproofs)** — pruebas visuales interactivas; **CC BY-NC 4.0**.

## 4. Portales institucionales (entrada, no PDF único)

Estos enlaces son **portales**: hay que navegar hasta el material concreto (departamento, REA, buscador).

- [IES Emilio Castelar (educa2.madrid)](https://www.educa2.madrid.org/web/centro.ies.emiliocastelar) — página del centro; buscar materiales/departamento de Matemáticas.
- [Ecoescuela / Medusa (Canarias)](https://www3.gobiernodecanarias.org/medusa/ecoescuela/) — entrada al ecosistema de recursos.
- [CEDEC (INTEF)](https://cedec.intef.es/) — REA, proyecto EDIA, buscador de recursos.

## Cómo contribuir

1. Fork del repositorio.
2. Añadir el enlace en la sección correspondiente.
3. Pull request con descripción breve **y licencia** del recurso.

También puedes abrir un *issue* para sugerir recursos o señalar enlaces rotos.
