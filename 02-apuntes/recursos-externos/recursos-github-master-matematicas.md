# Recursos en GitHub para el Máster de Profesorado de ESO – Matemáticas

Esta página recopila **repositorios de GitHub con licencia abierta** que pueden ser útiles para el Máster de Profesorado de Educación Secundaria Obligatoria, especialidad de Matemáticas. La mayoría son listas curadas (*awesome lists*), materiales didácticos, libros de texto abiertos y herramientas interactivas.

> **Licencias**: Todos los recursos enlazados son de código abierto o tienen licencias Creative Commons (CC BY, CC BY-SA, etc.). Verifica la licencia específica de cada repositorio antes de reutilizar su contenido.

---

## 1. Listas curadas de recursos matemáticos (*awesome lists*)

Estas listas recopilan cientos de enlaces a libros, cursos, herramientas y materiales de todo tipo. Son un excelente punto de partida para explorar.

- **rossant/awesome-math**  
  [https://github.com/rossant/awesome-math](https://github.com/rossant/awesome-math)  
  La lista de referencia: recursos de matemáticas de todos los niveles, incluyendo plataformas de aprendizaje, libros, blogs y herramientas. Muy útil para ampliar la formación disciplinar.

- **bryanwills/awesome-math**  
  [https://github.com/bryanwills/awesome-math](https://github.com/bryanwills/awesome-math)  
  Versión curada de la anterior, con énfasis en recursos de aprendizaje, enseñanza y resolución de problemas. Incluye enlaces a Khan Academy, MIT OpenCourseWare, Mathispower4u y WooTube (lecciones de matemáticas de secundaria).

- **brandonhimpfen/awesome-mathematics**  
  [https://github.com/brandonhimpfen/awesome-mathematics](https://github.com/brandonhimpfen/awesome-mathematics)  
  Recopilación que cubre teoría, pruebas, herramientas computacionales, conjuntos de datos y materiales de aprendizaje. Incluye una sección específica de recursos educativos.

- **ossu/math**  
  [https://github.com/ossu/math](https://github.com/ossu/math)  
  Currículo de autoaprendizaje en matemáticas, modelado a partir de los requisitos de una licenciatura. Ideal para reforzar la base matemática del profesorado.

- **FreeMathBooks/free-math-books-collection**  
  [https://github.com/FreeMathBooks/free-math-books-collection](https://github.com/FreeMathBooks/free-math-books-collection)  
  Colección de libros de texto de matemáticas gratuitos organizados por áreas: álgebra, geometría, cálculo, análisis, álgebra lineal, teoría de números, probabilidad y estadística.

## 2. Materiales didácticos para ESO y Bachillerato

Recursos directamente aplicables al aula de secundaria, con ejercicios, apuntes y programaciones.

- **fresdu/DocMath**  
  [https://github.com/fresdu/DocMath](https://github.com/fresdu/DocMath)  
  Sistema modular para apoyar la enseñanza de matemáticas en ESO basado en la metodología Craig Barton. Incluye ejercicios diferenciados (básico/medio/avanzado) y atención a la diversidad. Cubre números, fracciones, álgebra, geometría, funciones, etc.

- **pacoandres/apuntes_matematicas_secundaria**  
  [https://github.com/pacoandres/apuntes_matematicas_secundaria](https://github.com/pacoandres/apuntes_matematicas_secundaria)  
  Colección de apuntes de matemáticas para secundaria, ESO y bachillerato. Se aceptan contribuciones y correcciones a través de *issues*.

- **jmulet/llibre-matematiques-3eso**  
  [https://github.com/jmulet/llibre-matematiques-3eso](https://github.com/jmulet/llibre-matematiques-3eso)  
  Libro de matemáticas de 3º de ESO en catalán, derivado de la obra *Marea Verde de Matemáticas*. Ejemplo de adaptación de materiales abiertos.

- **oscarsanchezromero/Matematicas-con-Scratch**  
  [https://github.com/oscarsanchezromero/Matematicas-con-Scratch](https://github.com/oscarsanchezromero/Matematicas-con-Scratch)  
  Actividades con Scratch para practicar conceptos matemáticos de primaria y secundaria. Útil para introducir pensamiento computacional en el aula de matemáticas.

- **pbeltran/elemprob1**  
  [https://github.com/pbeltran/elemprob1](https://github.com/pbeltran/elemprob1)  
  Elementos para la enseñanza y aprendizaje de la probabilidad en 1º y 2º de ESO (12-14 años). Material listo para usar.

- **ilarrosa/GeoGebra**  
  [https://github.com/ilarrosa/GeoGebra](https://github.com/ilarrosa/GeoGebra)  
  Construcciones de GeoGebra para ESO y Bachillerato, incluyendo el teorema de Pitágoras, geometría euclídea, disecciones, polígonos, etc.

- **MMLand/TFM-2025-MAES**  
  [https://github.com/MMLand/TFM-2025-MAES](https://github.com/MMLand/TFM-2025-MAES)  
  Repositorio de documentos de interés adjunto a un Trabajo Fin de Máster del Máster Universitario en Profesorado de ESO y Bachillerato, especialidad Matemáticas. Ejemplo de estructura y materiales para el TFM.

## 3. Herramientas interactivas y simulaciones

Software y plataformas que permiten crear actividades interactivas, visualizaciones y ejercicios autocorregibles.

- **GeoGebra**  
  [https://github.com/kovzol/geogebra](https://github.com/kovzol/geogebra)  
  Repositorio oficial de GeoGebra, software de matemáticas dinámicas libre y de código abierto. Millones de recursos compartidos por la comunidad. Licencia: CC BY-SA.

- **Ximera**  
  [https://github.com/XimeraProject](https://github.com/XimeraProject)  
  Plataforma que permite convertir documentos LaTeX en actividades interactivas en línea. El código del *backend* está disponible en GitHub para su reutilización y redistribución.

- **visualproofs**  
  [https://github.com/visualproofs](https://github.com/visualproofs)  
  Plataforma abierta de pruebas visuales interactivas para estudiantes y profesores. Disponible bajo licencia CC BY-NC 4.0.

- **INNODEMS/CBC-Grade-10-Maths**  
  [https://github.com/INNODEMS/CBC-Grade-10-Maths](https://github.com/INNODEMS/CBC-Grade-10-Maths)  
  Libro de texto digital interactivo con ejercicios de evaluación automática (STACK) para matemáticas de secundaria. Ejemplo de cómo crear materiales autocorregibles con PreTeXt.

- **reamat/AlgebraLinear** (y otros repositorios de REAMAT)  
  [https://github.com/reamat/AlgebraLinear](https://github.com/reamat/AlgebraLinear)  
  Proyecto de escritura colaborativa de recursos educativos abiertos sobre álgebra lineal. Incluye libros de cálculo, análisis, transformadas, etc. Licencia abierta.

## 4. Programaciones didácticas y materiales curriculares

Ejemplos y plantillas de programaciones didácticas de matemáticas para ESO, útiles como referencia para el prácticum y el TFM.

- **Programación didáctica de Matemáticas – IES Emilio Castelar**  
  [https://www.educa2.madrid.org/web/centro.ies.emiliocastelar](https://www.educa2.madrid.org/web/centro.ies.emiliocastelar)  
  Ejemplo completo de programación didáctica de Matemáticas para 2025/2026, con saberes básicos, criterios de evaluación y situaciones de aprendizaje.

- **Programación didáctica 4º ESO Matemáticas B – Gobierno de Canarias**  
  [https://www3.gobiernodecanarias.org/medusa/ecoescuela/](https://www3.gobiernodecanarias.org/medusa/ecoescuela/)  
  Documento con saberes básicos, modelización geométrica y uso de herramientas digitales.

- **Proyecto EDIA – Matemáticas ESO**  
  [https://cedec.intef.es/](https://cedec.intef.es/)  
  Recursos educativos abiertos del proyecto EDIA, con situaciones de aprendizaje para matemáticas de ESO. Algunos materiales están alojados en GitHub.

## 5. Recursos en español y multilingües

- **Gate2Math**  
  [https://gate2math.eu/](https://gate2math.eu/)  
  Biblioteca inteligente de recursos matemáticos abiertos en siete idiomas (incluido el español). Dirigida a profesorado y estudiantes de secundaria, formación profesional y primeros cursos de ingeniería.

- **OER Smart Library (Gate2Math)**  
  [https://gate2math.eu/oer-smart-library/](https://gate2math.eu/oer-smart-library/)  
  Colección de vídeos, infografías, juegos, presentaciones y animaciones sobre álgebra, polinomios, funciones, etc.

- **reamat/AnaliseMatematica**  
  [https://github.com/reamat/AnaliseMatematica](https://github.com/reamat/AnaliseMatematica)  
  Proyecto de escritura colaborativa de recursos educativos abiertos sobre análisis matemático. Textos en portugués, pero con estructura y enfoque fácilmente adaptables.

## Cómo contribuir

Si conoces algún repositorio de GitHub con licencia abierta que encaje en esta lista, puedes:

1. Hacer un *fork* de este repositorio.
2. Añadir el enlace en la sección correspondiente.
3. Enviar un *pull request* con una breve descripción del recurso y su licencia.

También puedes abrir un *issue* para sugerir nuevos recursos o señalar enlaces rotos.
