# Historias matemáticas

Colección de **relatos, descubrimientos y anécdotas** que permiten introducir conceptos de Matemáticas en ESO y Bachillerato **sin empezar por la fórmula**.

La historia no es un adorno: es el marco de una **situación problemática**. El arco didáctico de cada ficha es:

```text
Historia → pregunta / problema → intentos → idea matemática
    → formalización (nivel del curso) → problema para el alumnado
```

## Criterios de calidad

- La pregunta inicial debe hacer *necesaria* la herramienta matemática.
- El relato es riguroso: se evita la mitología escolar sin matices (p. ej. «la manzana» como única explicación de Newton).
- Hay puente claro al objeto matemático y al nivel (ESO / Bachillerato).
- Cierra con una tarea para el alumnado, no solo con la anécdota.
