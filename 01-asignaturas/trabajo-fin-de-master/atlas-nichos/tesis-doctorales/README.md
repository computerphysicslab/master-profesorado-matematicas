# Tesis doctorales — capa de fundamento del Atlas de Nichos

Esta sección **no sustituye** a los ejemplos de TFM: documenta tesis doctorales (y alguna tesis de posgrado internacional comparable) que **marcan el estado del arte** en intersecciones relevantes para el Máster de Profesorado (Matemáticas).

## Cómo usarlas

1. Consultar el [ranking de intersecciones](../04-coocurrencias-y-ranking-v09.md).
2. Leer 1–2 fichas del nicho elegido como **marco teórico / límite de saturación**.
3. Diseñar el TFM con una **variable diferenciadora** (nivel, inclusión, GenAI, outdoor, socioafectivo medido, etc.).

## Criterio de inclusión
- Acceso abierto o metadatos verificables con enlace estable
- Relevancia para nichos prioritarios del Atlas (geometría+TIC, DGBL, GenAI, socioafectivo, formación docente, probabilidad)
- Preferencia 2020–2026

## Relación con el corpus TFM
Las tesis doctorales **suben el listón** de saturación: p. ej. TECGAFLIP implica que un TFM de geometría+gamificación+flipped debe aportar algo claramente distinto. Las internacionales (McGill, Genova) confirman que **videojuegos/espacial** e **IA generativa** siguen siendo huecos poco cubiertos en TFM españoles de máster profesorado.
