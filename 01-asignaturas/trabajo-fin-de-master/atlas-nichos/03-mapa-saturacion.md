# Mapa de saturación (esquema v0)

Representación **cualitativa** hasta disponer de coocurrencias numéricas (v1.0).

## Plano conceptual: densidad × centralidad

```text
                         DENSIDAD
                            ↑
                            │
              NICHOS        │        MOTORES
         (poco frecuente,   │   (frecuente y
          alta promesa)     │    estructurante)
                            │
                            │
       ─────────────────────┼────────────────────→ CENTRALIDAD
                            │
              EMERGENTES    │        BÁSICOS
         (nuevo, aún        │   (necesario pero
          poco articulado)  │    poco diferenciador)
                            │
                            │
```

### Lectura orientativa (v0)

| Cuadrante | Ejemplos tentativos |
|-----------|---------------------|
| **Motores** | Objeto matemático + secuencia didáctica; GeoGebra + funciones/álgebra |
| **Básicos** | Programación didáctica genérica; «uso de TIC» sin variable de aprendizaje |
| **Emergentes** | IA en el aula de mates (aún dispersa); RA/3D según contexto |
| **Nichos** | Videojuegos + espacial + geometría; IA + metacognición; gamificación + estadística; enriquecimiento medido |
