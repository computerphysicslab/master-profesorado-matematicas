# Fichas individuales de TFM

Reservado para fichas `tfm-NNN.md` cuando el corpus esté **contrastado** (URL estable, señales de influencia verificadas).

La preselección v0.1 no crea aún 20 fichas completas a propósito: evita convertir una lista exploratoria en un «ranking definitivo».

Plantilla sugerida cuando se añada una ficha:

```markdown
# TFM-NNN — Título corto

- Autor / año / universidad
- URL repositorio
- Tema y etapa
- Metodología
- Intervención y datos
- Publicación derivada (si existe)
- Señales de influencia
- Nivel de evidencia
- Relación con nichos del atlas
- Observaciones
```
