# Examen intermedio — Habilidades comunicativas

**Tiempo orientativo:** 40–55 min  
**Respuestas:** [respuestas-intermedio.md](respuestas-intermedio.md)

---

**1.** Explica con un ejemplo de aula de mates cómo el área **ciega** del docente puede aumentar la ansiedad matemática.

**2.** Diferencia empatía, compasión y el límite “empatía ≠ bajar el listón”.

**3.** Diseña un microguion (escucha → criterios → plan) ante un alumno que dice «no sirvo para las mates».

**4.** Compara IRF cerrado y diálogo exploratorio: cuándo usar cada uno.

**5.** Estructura una entrevista de 15 min con una familia disconforme con una calificación.

**6.** Reescribe tres mensajes minimizadores en mensajes de escucha activa + asertividad.

**7.** Relaciona esta optativa con el Tema 3 de SFYPG y con el feedback de Psicología Tema 5.
