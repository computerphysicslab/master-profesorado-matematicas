# TIC para el aprendizaje

**Tipo:** Optativa (S2)  
**Nombre completo en plan:** Tecnologías de la información y la comunicación para el aprendizaje  
**Máster en Profesorado** · Especialidad Matemáticas

## Enfoque

Usar la tecnología en el aula de Matemáticas con **criterio didáctico**: objetivo de aprendizaje primero, herramienta después. GeoGebra, aula virtual, hojas de cálculo, vídeo o IA generativa son **medios**, no el fin.

## Principio

> El software **no sustituye** la demostración ni el razonamiento: puede ayudar a **conjeturar, visualizar y verificar**.
