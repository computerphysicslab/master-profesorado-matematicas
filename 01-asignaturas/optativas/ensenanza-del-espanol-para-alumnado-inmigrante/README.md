# Enseñanza del español para alumnado inmigrante

**Tipo:** Optativa (S2)  
**Máster en Profesorado** · Especialidad Matemáticas

## Enfoque

Preparar al **docente de Matemáticas** para reducir barreras lingüísticas de acceso al aprendizaje matemático del alumnado que está aprendiendo español (o con español como L2), coordinar con los apoyos del centro y **no confundir** nivel de lengua con capacidad matemática.

> Esta optativa **no** forma profesorado especialista de ELE/español como lengua extranjera de forma completa: orienta la respuesta desde la materia Matemáticas.

## Principio

> Separar **barrera de lengua** y **competencia matemática**.  
> Limpiar enunciados y ofrecer múltiples representaciones **sin** vaciar el objetivo matemático.  
> Coordinar con el plan de acogida / apoyo lingüístico del centro.
