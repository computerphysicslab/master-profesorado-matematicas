# Examen — Educación emocional en el profesorado

Modelos de examen a tres niveles + respuestas para autoevaluación y preparación.

| Nivel        | Archivo de examen              | Respuestas                     | Descripción |
|--------------|--------------------------------|--------------------------------|-----------|
| **Fácil**    | [examen-facil.md](examen-facil.md) | [respuestas-facil.md](respuestas-facil.md) | Conceptos básicos + caso sencillo + actividad corta |
| **Intermedio** | [examen-intermedio.md](examen-intermedio.md) | [respuestas-intermedio.md](respuestas-intermedio.md) | Estructura clásica (preguntas + caso Adrián + sesión 50 min + reflexión) |
| **Difícil**  | [examen-dificil.md](examen-dificil.md) | [respuestas-dificil.md](respuestas-dificil.md) | Análisis teórico, caso complejo multi-nivel, secuencia de 3 sesiones, reflexión con evidencia |

**Criterios comunes**
- Alineados con los apuntes y materiales del repositorio.
- Enfocados en el rol docente (observar → prevenir → enseñar → intervenir según normas → derivar).
- Especial atención al aula de Matemáticas (ansiedad, error, pizarra, frustración).

> No son exámenes oficiales de convocatoria. Sirven para autoevaluación y preparación.
