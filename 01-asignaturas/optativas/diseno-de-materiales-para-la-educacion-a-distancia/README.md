# Diseño de materiales para la educación a distancia

**Tipo:** Optativa (S2)  
**Máster en Profesorado** · Especialidad Matemáticas

## Enfoque

Diseñar **materiales y secuencias** de Matemáticas para escenarios a distancia, híbridos o de apoyo asíncrono: claridad de consignas, carga cognitiva, evidencia de aprendizaje y equidad de acceso — no solo “subir el PDF del libro”.

## Principio

> A distancia el material **lleva más peso** de la mediación docente.  
> Diseñar para la **autonomía guiada**: objetivo claro, ejemplos, práctica con feedback y evidencia de lo aprendido.
