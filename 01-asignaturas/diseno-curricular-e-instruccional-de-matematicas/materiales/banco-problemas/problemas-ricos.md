# Problemas ricos para el aula

Cada ficha incluye enunciado, uso didáctico, estrategias esperables, mediación, errores productivos y orientación a criterios LOMLOE.

**Gestión de sesión (recordatorio):** comprensión → trabajo autónomo/parejas → mediación selectiva → puesta en común de *estrategias* → institucionalización → cierre ([bloque 8](../../apuntes/08-resolucion-de-problemas.md)).

## P1 · Tarifas de móvil (función afín / sistemas)

| Campo | Contenido |
|-------|-----------|
| **Curso** | 3.º–4.º ESO |
| **Enunciado** | La tarifa A cobra 12 € fijos al mes y 0,08 € por minuto de llamada. La tarifa B cobra 6 € fijos y 0,15 € por minuto. ¿A partir de cuántos minutos al mes conviene cada tarifa? Explica cómo lo sabes y representa la situación de más de una forma. |
| **Uso** | Introducir o consolidar función afín, comparación de modelos, sistemas $2\times2$ o intersección gráfica |
| **Estrategias esperables** | Tabla de valores; ensayo sistemático; ecuaciones $12+0{,}08x=6+0{,}15x$; gráficas de dos rectas |
| **Errónea productiva** | Comparar solo el fijo o solo el variable; olvidar las unidades |
| **Mediación** | «¿Qué coste con 0 minutos? ¿Con 100?» · «¿Cuándo se igualan?» |
| **Criterios (idea)** | Modelizar; representar; interpretar la solución en contexto; comunicar |
| **Ampliación** | Tercera tarifa; coste máximo 20 €; datos con IVA |
| **Ficha** | [Función lineal](../fichas-objetos/funcion-lineal.md) |

## P2 · Reparto de chocolate (fracciones)

| Campo | Contenido |
|-------|-----------|
| **Curso** | 1.º–2.º ESO |
| **Enunciado** | Hay que repartir 3 tabletas idénticas entre 4 personas a partes iguales. ¿Cuánto recibe cada una? Muestra el resultado con un dibujo, con una fracción y con una frase. ¿Es lo mismo que repartir *cada* tableta en 4 trozos y dar tres trozos a cada persona? |
| **Uso** | Fracción como cociente y como parte-todo; equivalencia |
| **Estrategias** | Diagramas de barras/círculos; $3\div4$; $3\times\frac{1}{4}$; repartir tableta a tableta |
| **Errónea productiva** | «A cada uno le toca 3/3»; sumar 3+4 en el denominador |
| **Mediación** | «¿Podéis cortar primero cada tableta en cuatro?» |
| **Criterios (idea)** | Representar; comunicar; sentido numérico |
| **Ampliación** | 5 tabletas entre 6; comparar con decimal |
| **Ficha** | [Fracción](../fichas-objetos/fraccion.md) |

## P3 · ¿Rectángulo? (Pitágoras)

| Campo | Contenido |
|-------|-----------|
| **Curso** | 2.º–3.º ESO |
| **Enunciado** | Un triángulo tiene lados 5, 12 y 13. Otro tiene lados 5, 12 y 14. ¿Cuál es rectángulo? ¿Puedes decidirlo sin transportador ni escuadra? Argumenta. |
| **Uso** | Necesidad del criterio de Pitágoras (y su reciproco) |
| **Estrategias** | Comprobar $a^2+b^2=c^2$; dibujo a escala; comparación de ángulos por construcción |
| **Errónea productiva** | «El más puntiagudo es el rectángulo»; aplicar Pitágoras sin identificar la hipotenusa |
| **Mediación** | «En un rectángulo, ¿qué relación hay entre los lados?» |
| **Criterios (idea)** | Conjeturar y comprobar; argumentar; sentido espacial |
| **Ampliación** | Generar triples pitagóricos; triángulo 6, 8, 10 y semejanza |

## P4 · Dados y esperanza (probabilidad)

| Campo | Contenido |
|-------|-----------|
| **Curso** | 2.º–4.º ESO |
| **Enunciado** | Si lanzáis un dado equitativo 60 veces, ¿cuántas veces esperáis sacar un 6? Haced el experimento (o simulación) en clase y comparad con vuestra predicción. ¿Saldrá *exactamente* el número esperado? ¿Qué pasaría con 6000 lanzamientos? |
| **Uso** | Enfoque clásico vs frecuencial; variabilidad |
| **Estrategias** | $\frac{1}{6}\times 60$; experimento; gráfico de frecuencias; debate |
| **Errónea productiva** | «Tiene que salir exactamente 10 veces»; falacia del jugador al interpretar rachas |
| **Mediación** | «¿El modelo describe una *tendencia* o un resultado fijo?» |
| **Criterios (idea)** | Estocástico; analizar la razonabilidad; comunicar |
| **Ampliación** | Dado trucado; chincheta; comparar grupos de la clase |
| **Ficha** | [Probabilidad](../fichas-objetos/probabilidad.md) |

## P5 · Dos caminos al mismo sistema (álgebra)

| Campo | Contenido |
|-------|-----------|
| **Curso** | 3.º–4.º ESO |
| **Enunciado** | «La entrada de adulto cuesta 3 € más que la de menor. Dos adultos y tres menores pagan 39 €. ¿Cuánto cuesta cada entrada?» Resuelve de al menos dos maneras distintas y explica cuál te resulta más clara. |
| **Uso** | Ecuaciones / sistemas; comparación de estrategias |
| **Estrategias** | Sustitución; igualación; ensayo sistemático con tabla; modelo con una sola incógnita |
| **Errónea productiva** | Plantear $2a+3m=39$ sin relacionar $a$ y $m$ |
| **Mediación** | «¿Qué datos relacionan adulto y menor?» |
| **Criterios (idea)** | Modelizar; elegir estrategia; comunicar; analizar la solución |
| **Ampliación** | Cambiar precios; tres tipos de entrada |

## P6 · Velocidad instantánea (derivada)

| Campo | Contenido |
|-------|-----------|
| **Curso** | 1.º Bachillerato |
| **Enunciado** | Un móvil recorre $s(t)=t^2$ metros en $t$ segundos (modelo simplificado). ¿Cuál es la velocidad media entre $t=1$ y $t=3$? ¿Cómo estimarías la velocidad *en* $t=2$? Usa al menos una tabla de intervalos cada vez más pequeños y una gráfica. |
| **Uso** | Génesis de la derivada como ritmo instantáneo |
| **Estrategias** | Cocientes $\frac{\Delta s}{\Delta t}$; secantes en GeoGebra; conjetura del valor límite |
| **Errónea productiva** | Confundir velocidad media del intervalo con la de un extremo; «en $t=2$ no se puede saber» |
| **Mediación** | «Acerca el segundo instante a 2» |
| **Criterios (idea)** | Modelizar el cambio; herramientas tecnológicas; comunicar interpretación |
| **Ampliación** | Interpretar $s'(2)$ en unidades; comparar con otro $s(t)$ |
| **Ficha** | [Derivada](../fichas-objetos/derivada.md) |

## P7 · Gráfico dudoso (estadística crítica)

| Campo | Contenido |
|-------|-----------|
| **Curso** | 3.º–4.º ESO / Bachillerato CCSS |
| **Enunciado** | Se muestra un gráfico de barras con el eje vertical *empezando en 80* (no en 0) que parece mostrar una subida «enorme» de un 2 %. ¿Qué mensaje visual transmite? Redibuja el gráfico de forma más honesta y escribe un titular que no engañe. |
| **Uso** | Lectura crítica; sentido estocástico y ciudadanía |
| **Estrategias** | Recalcular escala; comparar frecuencias absolutas; debate |
| **Errónea productiva** | «El gráfico del periódico no puede mentir» |
| **Mediación** | «¿Qué fracción del eje se está ocultando?» |
| **Criterios (idea)** | Analizar información; comunicar; actitud crítica |
| **Ampliación** | Buscar un gráfico real de prensa (anonimizado) y analizarlo |

## P8 · Escalado de una figura (semejanza y área)

| Campo | Contenido |
|-------|-----------|
| **Curso** | 3.º ESO |
| **Enunciado** | Una figura se amplía con factor $k=2$. Un alumno dice: «El área también se multiplica por 2». ¿Está de acuerdo? Argumenta con un rectángulo concreto y, si puedes, con un razonamiento general. |
| **Uso** | Efecto de la semejanza sobre longitudes y áreas |
| **Estrategias** | Ejemplo numérico; cuadrícula; factor $k^2$ |
| **Errónea productiva** | Confundir perímetro y área bajo el mismo factor |
| **Mediación** | «¿Qué pasa con la base y con la altura?» |
| **Criterios (idea)** | Conjeturar; argumentar; sentido espacial y de la medida |
| **Ampliación** | Factor $3$; volumen en $k^3$ (preview) |

## Cómo ampliar el banco

Al añadir un problema, incluye como mínimo:

1. Enunciado completo  
2. Curso y objeto  
3. Dos estrategias legítimas + una errónea productiva  
4. Una pregunta de mediación  
5. Qué criterio o competencia evidencia  
6. Una variante de ampliación o refuerzo  

Plantilla vacía: puedes copiar la estructura de P1.
