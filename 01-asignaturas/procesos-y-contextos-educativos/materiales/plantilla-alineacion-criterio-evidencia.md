# Plantilla de alineación · criterio → tarea → evidencia → instrumento

**Temas 5–6** · Una página para diseñar cualquier unidad o situación de aprendizaje.

```text
Competencia específica
        ↓
Criterio(s) de evaluación
        ↓
Saberes / sentidos implicados
        ↓
Tarea o situación de aprendizaje
        ↓
Evidencia observable
        ↓
Instrumento y momento (formativo / sumativo)
```

## Ejemplo rellenado (3.º ESO — proporcionalidad)

| Campo | Contenido |
|-------|-----------|
| Criterio (idea) | Modeliza e interpreta situaciones de proporcionalidad |
| Saberes | Razones, porcentajes, regla de tres; tabla y gráfica |
| Tarea | Comparar dos descuentos en un mismo producto |
| Evidencia | Tabla + elección argumentada en 4–6 líneas |
| Instrumento | Producto breve + rúbrica de comunicación (niveles 1–4) |
| Formativo | Ticket: “¿cuándo un descuento del 30 % no es el mejor?” |
| DUA | Contexto a elegir (ropa / datos móviles); opción oral |

## Autocomprobación

- [ ] Si cambio solo el número del resultado, ¿sigo pudiendo evaluar el criterio? → si no, falta proceso/interpretación.  
- [ ] ¿El alumnado conoce el criterio con antelación?  
- [ ] ¿Hay al menos una evidencia formativa antes de la sumativa?
