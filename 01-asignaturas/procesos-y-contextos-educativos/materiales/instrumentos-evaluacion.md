# Banco de instrumentos de evaluación

**Tema 6** · Elige el instrumento según el **criterio**, no al revés.

## Catálogo breve

| Instrumento | Qué evidenció bien | Ejemplo en Matemáticas |
|-------------|--------------------|------------------------|
| **Prueba escrita contextual** | Resolver, analizar, a veces modelizar | Tarifas, escalas, datos de un gráfico |
| **Portfolio** | Evolución, corrección de errores | 5 problemas con “versión 1 / versión mejorada” |
| **Lista de cotejo** | Proceso observable, cooperativo | Roles en grupo; uso de representaciones |
| **Rúbrica de comunicación** | Explicar y argumentar | Niveles: solo número → proceso → porqué en contexto |
| **Ticket de salida** | Formativo rápido | “Una duda y un logro de hoy” (3 min) |
| **Producto** (póster, audio, vídeo corto) | Representar y comunicar | Explicar una función con tres registros |
| **Entrevista / defensa** | Argumentación oral | 2 min: “¿por qué descartas esta solución?” |
| **Observación sistemática** | Socioafectivo, perseverancia | Indicadores: pide ayuda con criterio; revisa el resultado |

## Mini-rúbrica de comunicación (4 niveles)

| Nivel | Descriptor |
|-------|------------|
| 1 | Resultado sin explicación |
| 2 | Pasos mecánicos sin interpretar |
| 3 | Proceso claro + sentido de la solución |
| 4 | Proceso + límites del modelo o error típico anticipado |

## Lista de cotejo (cooperativo — ejemplo)

- [ ] Escucha y turnos  
- [ ] Aporta una representación o estrategia  
- [ ] Comprueba la razonabilidad del resultado  
- [ ] Puede explicar el acuerdo del equipo  

## Ticket de salida (plantilla)

```text
Hoy aprendí: _______________________
Me bloqueé en: _____________________
Mañana probaré: ____________________
```

## Aviso de alineación

Si el criterio pide **interpretar en contexto** y el examen solo pide el número, el instrumento está mal elegido.
