# Glosario — Procesos y contextos educativos

| Término | Definición operativa |
|---------|----------------------|
| **Paradigma educativo** | Marco teórico-metodológico que orienta enseñanza, rol docente y función social de la escuela |
| **Positivista / técnico** | Énfasis en transmisión, objetivos medibles, evaluación sumativa estandarizada |
| **Interpretativo** | Construcción de significado; docente mediador; evaluación procesual |
| **Sociocrítico** | Equidad, transformación, participación, investigación-acción |
| **SEE** | Sistema Educativo Español |
| **ESO** | Educación Secundaria Obligatoria |
| **FP** | Formación Profesional (grados básico, medio, superior) |
| **Régimen especial** | Enseñanzas de idiomas, artísticas, deportivas (paralelas a la ordinaria) |
| **Equipo directivo** | Órganos unipersonales de gobierno: director/a, jefe/a de estudios y secretario/a |
| **Consejo Escolar** | Órgano colegiado de participación de toda la comunidad educativa (profesorado ≥1/3, familias+alumnado ≥1/3, PAS, Ayuntamiento, dirección) |
| **Claustro** | Órgano colegiado de participación del profesorado; integrado por la totalidad del claustro del centro |
| **CCP** | Comisión de coordinación pedagógica (o equivalente): coherencia entre departamentos y con el PEC |
| **Departamento didáctico** | Órgano de coordinación por área; reuniones semanales obligatorias; programación y criterios comunes |
| **PEC / PE** | Proyecto educativo de centro: identidad, valores, objetivos y contexto («ADN del centro») |
| **PGA** | Programación general anual: plan concreto del curso |
| **POAT** | Plan de orientación y acción tutorial |
| **NOF / RRI** | Normas de organización y funcionamiento / reglamento de régimen interior |
| **Proyecto de dirección** | Documento que presenta el candidato a director (objetivos, líneas de actuación, evaluación); requisito del concurso de méritos |
| **Órganos de coordinación docente** | Departamentos, Orientación, CCP, juntas de evaluación, tutorías: organizan e implementan las enseñanzas |
| **NEAE** | Necesidades específicas de apoyo educativo |
| **DUA / UDL** | Diseño Universal para el Aprendizaje |
| **Medidas ordinarias / específicas** | Respuestas a la diversidad desde el diseño común vs. planes individualizados |
| **Evaluación criterial** | Referida a criterios de evaluación del currículo |
| **Evaluación formativa** | Orientada a mejorar el proceso mientras aún se puede intervenir |
| **Evaluación sumativa** | Certifica el grado de logro al cierre de un periodo |
| **Alineación** | Coherencia criterios ↔ enseñanza ↔ calificación |
| **Ratio** | Relación alumnado/grupo o alumnado/docente |
| **Aprendizaje cooperativo** | Trabajo en equipo con interdependencia positiva y responsabilidad individual |
| **Situación de aprendizaje** | Escenario contextualizado que moviliza competencias y saberes |
| **Perfil de salida** | Conjunto de competencias clave que el alumnado debe haber desarrollado al finalizar la educación básica (LOMLOE) |
