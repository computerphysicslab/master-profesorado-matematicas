# Estructuras de aprendizaje cooperativo (ficha)

**Temas 4–5** · Inspirado en la línea de implantación de **Torrego y Negro** (cooperar ≠ “hacer grupos”).

## Condiciones mínimas

1. **Interdependencia positiva** — el equipo necesita a todos.  
2. **Responsabilidad individual** — cualquiera puede ser preguntado.  
3. **Interacción real** — hablar, argumentar, corregir.  
4. **Habilidades sociales** — turnos, respeto, ayuda.  
5. **Reflexión de equipo** — qué estrategia funcionó.

## Estructuras listas para Matemáticas

| Estructura | Cómo se hace | Ejemplo |
|------------|--------------|--------|
| **1-2-4** | Individual → pareja → cuarteto | Resolver un problema de proporcionalidad y consensuar una explicación |
| **Lápices al centro** | Mientras se discute, nadie escribe; luego todos escriben la versión acordada | Elegir método para un sistema 2×2 |
| **Roles rotativos** | Representa / Calcula / Explica / Revisa | Función lineal: de tabla a gráfica y a expresión |
| **Cabezas numeradas** | El docente dice un número; ese miembro responde por el equipo | Corrección de un error típico de signos |
| **Parejas cooperativas** | A resuelve, B cuestiona; se invierten | Interpretar un gráfico estadístico engañoso |
| **Corrección cruzada** | Intercambio con pauta de 3 ítems | “¿Resultado razonable? ¿Unidades? ¿Proceso legible?” |

## Roles sugeridos (rotar cada sesión o tarea)

| Rol | Función |
|-----|--------|
| **Representa** | Dibujar, tabular, traducir al lenguaje gráfico |
| **Calcula** | Ejecutar con cuidado el procedimiento acordado |
| **Explica** | Poner en palabras el porqué |
| **Revisa** | Buscar contradicciones y sentido de la solución |

## Evaluación (para que no se diluya el aprendizaje)

- Nota o evidencia **individual** + breve evidencia de proceso grupal.  
- Pregunta aleatoria a un miembro.  
- Ticket de salida personal: “una idea del equipo que yo no tenía”.

## Errores frecuentes

- Grupas fijos siempre con el mismo “que se lo sabe”.  
- Tarea que puede hacer uno solo (no hay interdependencia).  
- Ruido sin pauta ni tiempo límite.  
- Evaluar solo el producto final del más rápido.
