# Misma tarea de Matemáticas · tres lecturas paradigmáticas

**Tema 1** · Entrenar el ojo: el enunciado puede parecer “neutral”; el **diseño completo** (consigna, interacción, evaluación) delata el paradigma.

## La tarea base

> *Un plan de datos móviles cuesta 8 € de cuota y 0,10 € por cada 100 MB extra. Otro cuesta 12 € y 0,05 € por cada 100 MB extra. ¿A partir de qué consumo conviene cada uno?*

---

## Lectura **positivista / técnica**

| Elemento | Cómo se concreta |
|----------|------------------|
| Objetivo | Aplicar correctamente el procedimiento de ecuaciones o sistemas |
| Rol docente | Explica el método modelo; supervisa la ejecución |
| Rol alumnado | Reproduce el algoritmo |
| Evaluación | Resultado numérico exacto; penaliza el fallo de cálculo |
| Éxito | “Lo resolvió como en la pizarra” |

---

## Lectura **interpretativa**

| Elemento | Cómo se concreta |
|----------|------------------|
| Objetivo | Construir el significado de “punto de equilibrio” con varias representaciones |
| Rol docente | Media: pide tabla, gráfica y expresión; cuestiona |
| Rol alumnado | Explora, compara estrategias, explica el sentido |
| Evaluación | Proceso + interpretación (“a partir de X MB…”) |
| Éxito | Puede traducir entre registros y justificar la elección |

---

## Lectura **sociocrítica**

| Elemento | Cómo se concreta |
|----------|------------------|
| Objetivo | Usar el modelo para decidir y **cuestionar** la letra pequeña (datos que no entran en el modelo) |
| Rol docente | Introduce variables sociales: ¿quién puede pagar la cuota alta? ¿publicidad engañosa? |
| Rol alumnado | Argumenta la decisión y los límites del modelo |
| Evaluación | Comunicación + conciencia de supuestos (contexto, desigualdad de acceso) |
| Éxito | No solo calcula: **juzga** la utilidad y los sesgos de la modelización |

---

## Idea clave

Los tres pueden usar la misma “cuenta”. Cambian la **pregunta que cuenta**, la interacción y lo que se califica. La LOMLOE empuja hacia lecturas interpretativas y sociocríticas **sin renunciar** a la corrección técnica.
