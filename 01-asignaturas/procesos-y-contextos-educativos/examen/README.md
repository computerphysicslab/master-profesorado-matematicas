# Examen — Procesos y contextos educativos

Material de **autoevaluación y preparación** a partir de apuntes y materiales del repositorio.  
**No** son preguntas oficiales de ninguna convocatoria.

## Niveles de examen

| Nivel | Archivo | Enfoque | Tiempo orientativo |
|-------|---------|---------|-------------------|
| **Fácil** | [examen-facil.md](examen-facil.md) | Recordar y reconocer (definiciones, V/F, emparejamientos) | 30–40 min |
| **Intermedio** | [examen-intermedio.md](examen-intermedio.md) | Comparar, explicar y aplicar con ejemplos de Matemáticas | 45–60 min |
| **Difícil** | [examen-dificil.md](examen-dificil.md) | Casos, argumentación, síntesis entre leyes/paradigmas/aula | 75–90 min |

## Respuestas de autocorrección

→ **[respuestas-autocorreccion.md](respuestas-autocorreccion.md)** — respuestas breves orientativas por nivel.  
Úsalas **después** de intentar el examen; no sustituyen el juicio de un corrector ni la guía docente.

## Criterios de elaboración

- Alineadas con apuntes y materiales del repo (paradigmas, leyes, burocracia, DUA, estructura del sistema, centros, evaluación competencial).
- Orientadas a profesorado de **Matemáticas** (ESO / Bachillerato).
- Formatos: corta, V/F justificado, comparación, caso, desarrollo.

## Uso recomendado

1. Empezar por **fácil** si se revisa el tema por primera vez.  
2. Pasar a **intermedio** cuando se dominan definiciones y tablas.  
3. Reservar **difícil** para simular examen o oral con casos.  
4. Contrastar con [respuestas-autocorreccion.md](respuestas-autocorreccion.md) y volver a los apuntes/materiales donde falle la respuesta.
