# Practicum — espacio de trabajo integrado

Carpeta transversal para el **Practicum I** y el **Practicum II** del máster (especialidad Matemáticas).

## Principios de privacidad

> **Importante:** no se almacenan datos personales de alumnado, nombres de centros, de profesorado tutor ni documentos confidenciales.  
> Toda la información aquí es **anonimizada o simulada** con fines formativos. Cualquier coincidencia con centros o personas reales es casual.

## Estructura

| Carpeta | Contenido |
|---------|-----------|
| [observacion/](observacion/) | Guías y registros de observación (anonimizados) |
| [centro/](centro/) | Análisis del centro educativo (sin identificar) |
| [aula/](aula/) | Análisis de aula y organización espacial/temporal |
| [alumnado/](alumnado/) | Perfiles de grupo y necesidades (sin nombres) |
| [profesor-tutor/](profesor-tutor/) | Rol del tutor/a y dinámica de acompañamiento (anonimizado) |
| [actividades/](actividades/) | Modelos de actividades diseñadas e implementadas |
| [diario/](diario/) | Diario de observación y práctica |
| [memoria/](memoria/) | Estructura y borradores de la memoria de prácticas |
| [reflexiones/](reflexiones/) | Reflexión sobre la práctica y contraste teoría–aula |
| [evidencias/](evidencias/) | Evidencias de aprendizaje (rúbricas, capturas sin datos personales) |

## Relación con asignaturas del máster

El Practicum conecta especialmente con: Psicología del desarrollo, Procesos y contextos, Diseño curricular, Diseño de actividades, Innovación e investigación, y Evaluación.
