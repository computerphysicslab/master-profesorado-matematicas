# Diario de observación y práctica

Entradas **anonimizadas** del practicum (especialidad Matemáticas). Sin nombres de personas, centro, calles ni datos identificativos.

## Cómo usar este diario

1. Copia [**plantilla.md**](plantilla.md) para cada semana (o cada sesión intensa).  
2. Rellena en caliente lo factual; deja la reflexión para el mismo día o al día siguiente.  
3. Cruza con el [checklist de sesión](../observacion/checklist-sesion-mates.md) cuando observes o impartas.  
4. Marca 1–2 **puentes al máster** (no hace falta citar diez teorías por semana).  
5. Al preparar la [memoria](../memoria/estructura.md), reutiliza bloques “Qué observé / Errores / Una cosa a mejorar”.

## Focos orientativos por fase

| Semanas | Foco típico |
|---------|-------------|
| 1–2 | Centro, rutinas, observación, códigos E1/E2… |
| 3–4 | Apoyo, errores recurrentes, primeras intervenciones breves |
| 5–6 | Tramos de clase, evaluación formativa, cierre hacia memoria |

Adapta el número de semanas a tu calendario real de Practicum I / II.

## Privacidad (imprescindible)

- Códigos: *Grupo A*, *E3*, *sesión de proporcionalidad*.  
- Nada de fotos con caras, listados, calificaciones nominativas ni chats.  
- Si una anécdota solo se entiende con el nombre, **no la escribas** aquí.
