# Observación — Practicum

Guías y plantillas para registrar lo observado en el aula de **Matemáticas** **sin datos personales**.

| Recurso | Uso |
|---------|-----|
| [guia-observacion.md](guia-observacion.md) | Guía general + **lentes** (cognición, motivación, conducta, grupo, inclusión) |
| [checklist-sesion-mates.md](checklist-sesion-mates.md) | Lista corta por sesión (imprimible / diario) |
| [observaciones-didacticas.md](observaciones-didacticas.md) | Síntesis de patrones (anonimizada, formativa) |

**Privacidad:** no nombres, no calificaciones individuales, no datos de salud/familia, no fotos con rostros.

**Puentes teóricos del máster**

- Psicología Temas 2–5 (diferencias, conducta/ABC, cognición, motivación)
- SFYPG (grupo, poder, comunicación, estereotipos, familias)
- Diseño de actividades (tarea, secuenciación, feedback)
