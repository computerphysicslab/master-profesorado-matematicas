# Guía de observación (anonimizada)

**Asignatura:** Practicum · Especialidad Matemáticas  
**Uso:** registrar y reflexionar sin identificar personas ni centros.

---

## 1. Principios

1. Observar para **aprender a enseñar**, no para juzgar al tutor.
2. Separar **descripción** (qué ocurre) de **interpretación** (hipótesis).
3. Una sesión no prueba una teoría: busca **patrones** a lo largo de días.
4. Todo lo registrado aquí debe poder mostrarse en una memoria **sin** datos personales.

---

## 2. Qué registrar (núcleo)

1. **Objetivo aparente** de la sesión (anunciado o inferido).
2. **Estructura temporal** (inicio / desarrollo / cierre; tiempos aproximados).
3. **Tipo de tareas** (exposición, práctica guiada, problema, debate, software…).
4. **Interacciones:** quién habla (roles, no nombres); tiempo de voz docente vs alumnado.
5. **Errores y estrategias** visibles (genéricos: tipo de fallo, no “el alumno X”).
6. **Recursos** (pizarra, GeoGebra, manipulativos, cuaderno, proyector).
7. **Clima ante el error** y la pizarra (amenaza vs información).

### Qué no registrar

- Nombres de estudiantes o docentes.
- Calificaciones individuales.
- Información de salud, familia o convivencia identificable.
- Capturas con rostros o listados.

---

## 3. Plantilla breve (por sesión)

```text
Fecha (solo mes/semana del practicum): ___
Curso/nivel (genérico): ___
Tema matemático: ___
Objetivo de la sesión: ___
Disposición del aula: ___
Fases y tiempos aproximados: ___
Tareas principales: ___
Errores / obstáculos observados (genéricos): ___
Preguntas del alumnado (tipos, no autores): ___
Notas para mi próxima intervención: ___
```

Para una lista aún más corta: [checklist-sesion-mates.md](checklist-sesion-mates.md).

---

## 4. Lentes de observación (conectar con el máster)

Usa **una o dos lentes por sesión** (no todas a la vez). Marca evidencias descriptivas.

### 4.1. Cognición y carga (Psicología Tema 4 · Diseño de actividades)

| Pregunta | Notas (descriptivas) |
|----------|----------------------|
| ¿La tarea separa lo nuevo de lo ya conocido o mezcla demasiados focos a la vez? | |
| ¿Hay carga extrínseca (enunciado confuso, figura ruidosa, consignas largas)? | |
| ¿Se usan representaciones múltiples (verbal, gráfica, simbólica, manipulativa)? | |
| ¿Hay andamiaje que se retira o solo “el docente resuelve”? | |
| ¿Se pide transferencia o solo repetición del mismo tipo? | |

### 4.2. Motivación, error y feedback (Psicología Tema 5)

| Pregunta | Notas |
|----------|-------|
| ¿El feedback es de proceso/estrategia o de persona/resultado? | |
| ¿El error se ridiculiza, se ignora o se usa como información? | |
| ¿Hay metas de dominio (“comprender”) o solo de rendimiento/evitación? | |
| ¿La pizarra es amenaza o espacio de ensayo? | |
| ¿Se ve autoeficacia baja (evitación inmediata, “yo no…”) sin etiquetar a nadie? | |

### 4.3. Conducta y gestión (Psicología Tema 3)

| Pregunta | Notas |
|----------|-------|
| ¿Se pueden esbozar antecedentes → conducta → consecuencia (ABC) de un patrón reiterado? | |
| ¿Qué conductas se refuerzan (atención, risa, que el docente resuelva)? | |
| ¿Las normas son claras y coherentes con el plan de convivencia (sin usar la nota de mates como sanción)? | |

### 4.4. Grupo, poder y comunicación (SFYPG Temas 1–3)

| Pregunta | Notas |
|----------|-------|
| ¿Quién monopoliza la palabra? ¿Hay tiempo de espera tras preguntas? | |
| ¿El patrón es IRF cerrado o hay diálogo exploratorio? | |
| ¿El trabajo “en grupo” es cooperación real (interdependencia + responsabilidad individual) o solo mesas juntas? | |
| ¿Hay líder informal que resuelve por el resto? | |

### 4.5. Inclusión, estereotipos y diversidad (Psicología Tema 2 · SFYPG Tema 4 · Procesos/DUA)

| Pregunta | Notas |
|----------|-------|
| ¿Se oyen etiquetas de capacidad (“de mates / de letras”, “esto es fácil”)? | |
| ¿Las preguntas difíciles se distribuyen o siempre a los mismos perfiles? | |
| ¿Hay ajustes ordinarios visibles (representaciones, tiempo, formatos) sin rebajar el objetivo? | |
| ¿Ante dificultad persistente se observa solo “más de lo mismo” o también coordinación/derivación (sin diagnosticar tú)? | |

---

## 5. Cómo pasar de observación a reflexión

1. **Describir** un episodio (30–60 s de clase) sin adjetivos de persona.  
2. **Elegir un concepto** del máster (carga, ZDP, ABC, meta de evitación, IRF, estereotipo…).  
3. **Formular una hipótesis** (“puede que…”) y una **alternativa de actuación** que probarías tú.  
4. Llevarlo a [reflexiones/teoria-vs-aula.md](../reflexiones/teoria-vs-aula.md) o al diario.
