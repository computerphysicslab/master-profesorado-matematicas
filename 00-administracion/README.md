# Administración del máster

Espacio de **seguimiento burocrático** del Máster Universitario en Profesorado (especialidad Matemáticas): matrícula, documentación, calendario, Practicum, TFM y trámites habituales durante el curso.

> **Aviso.** Este material es una **guía de trabajo personal** para ordenar el proceso administrativo típico de un máster habilitante de profesorado en el sistema universitario español. **No sustituye** la información oficial de la universidad en la que se curse el título, ni las resoluciones de admisión, matrícula, precios públicos o calendarios académicos del curso vigente. Fechas y plazos aquí son **orientativos** (patrón habitual); hay que contrastarlos cada año con la web y la secretaría del centro.

## Mapa rápido del proceso

```text
Admisión (fases) → Matrícula en plazo → Entrega de documentación
        ↓
Clases S1 → Practicum I → Clases S2 / optativas → Practicum II
        ↓
TFM (elaboración + depósito + defensa) → Título / resguardo
```
