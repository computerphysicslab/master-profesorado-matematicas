# 02. Evolución curricular (LGE → LOMLOE)

> Bloque del programa de **Diseño curricular e instruccional de Matemáticas**.  
> Volver al [índice de SA](../README.md).

## Enfoque

Todas las SA de este catálogo están formuladas en clave **LOMLOE** (competencias específicas, saberes/sentidos, situaciones de aprendizaje).

No sustituyen el estudio histórico LGE → LOGSE → LOE → LOMCE → LOMLOE: para eso están los apuntes de evolución curricular de la asignatura.

## Uso didáctico

Comparar una SA LOMLOE con cómo se habría formulado el mismo tema bajo LOMCE (estándares) ayuda a ver el cambio de lenguaje curricular.
