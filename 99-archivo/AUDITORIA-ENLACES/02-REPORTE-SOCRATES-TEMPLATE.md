# Plantilla de reporte — Auditoría de enlaces de autor

Usar como modelo el archivo `autores/socrates-auditoria.md`.

## Estructura obligatoria

```md
# Auditoría - {Autor}

- Ficha: {ruta o NO EXISTE / FICHA PENDIENTE}
- Menciones totales (estimación): {n}
- Enlaces actuales a la ficha: {n}
- Listado de enlaces (archivo)
- Huecos críticos (mención sustantiva sin enlace)
- Propuesta de enlaces | Archivo | Texto actual | Propuesta con ruta relativa |
- Prioridad: alta / media / baja
```

## Criterios

- **Sustantivo** → debe enlazar (concepto explicado o usado pedagógicamente).
- **Tangencial** (solo nombre en lista cronológica) → enlace opcional.
- Rutas **relativas** desde el archivo origen, no URLs absolutas de GitHub.
