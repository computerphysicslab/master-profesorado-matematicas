# Plantilla: documentar el proceso cuando se usa IA

**Para el alumnado** (ESO / Bachillerato).  
**Cuándo usarla:** tareas en las que el uso de IA está **permitido y debe declararse**.

El objetivo no es rellenar burocracia: es dejar visible qué hiciste tú y qué hizo la herramienta, y cómo lo comprobaste.

---

## Instrucciones breves para el alumnado

1. Completa las secciones **después** de trabajar (o mientras, si te ayuda).
2. No hace falta pegar conversaciones enteras: bastan los prompts clave y un resumen.
3. Si no usaste IA, indícalo en la sección 1 y entrega solo tu proceso habitual.

---

## 1. Declaración de uso

| Campo | Tu respuesta |
|-------|----------------|
| ¿Has usado IA en esta tarea? | Sí / No |
| Herramienta(s) | (p. ej. ChatGPT, Claude, Wolfram\|Alpha, GeoGebra…) |
| ¿Para qué la usaste? | (p. ej. pistas, variantes, comprobar un cálculo, reformular un enunciado…) |
| ¿Qué **no** le pediste? | (p. ej. la solución completa del ejercicio de evaluación) |

---

## 2. Producto final

Aquí va tu **entrega** (resolución, informe, gráfica, código…): la versión que consideras correcta y tuya.

## 4. Decisiones que tomaste tú

Responde en 4–8 líneas:

- ¿Qué parte del razonamiento es **tuya** (antes o después de la IA)?
- ¿Qué sugerencia de la IA **rechazaste** y por qué?
- ¿Cambiaste números, contexto o estrategia respecto a lo que propuso la herramienta?

---

## 5. Verificación

Indica **al menos dos** comprobaciones que hayas hecho:

| Tipo de comprobación | Qué hiciste | Resultado |

| Caso numérico / sustituir valores | | |
| Dominio / restricciones del enunciado | | |
| Otra representación (tabla, gráfica, GeoGebra…) | | |
| Orden de magnitud / caso límite | | |
| Comparar con otra herramienta o con un compañero | | |
| Otro | | |

---

## 6. Reflexión breve (opcional, 3–5 líneas)

- ¿En qué te ayudó la IA?
- ¿En qué te podría haber despistado?
- ¿Qué harías distinto la próxima vez?

---

## Nota para el docente

- Esta plantilla se evalúa con la [rúbrica de uso de IA](rubricas-uso-ia.md) **además** de los criterios matemáticos de la tarea.
- No sustituye la defensa oral ni las evidencias sin dispositivo cuando la programación las prevea.
- Puede usarse en papel (tabla impresa) o en el portfolio digital del centro.
- Si la norma de aula **prohíbe** IA en esa tarea, no se entrega esta plantilla: se aplica el protocolo de la norma.
