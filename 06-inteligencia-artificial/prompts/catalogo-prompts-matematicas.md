# Catálogo de prompts para Matemáticas (ESO y Bachillerato)

Prompts listos para copiar, adaptar y usar. **Revisa siempre** la salida antes de llevarla al aula.

---

## 1. Diseño de actividades y problemas

### Generar variantes de un problema

```
Eres profesor de Matemáticas de 3.º ESO (LOMLOE).
A partir del siguiente problema, genera 4 variantes que midan el mismo criterio de evaluación pero cambien números, contexto o representación.
No cambies la estructura cognitiva principal.
Problema original:
[pegar problema]
Para cada variante indica: qué se mantiene y qué se cambia.
```

### Generar problemas con autenticidad contextual

```
Eres diseñador de materiales de Matemáticas para 4.º ESO.
Diseña 3 problemas de [tema] que usen datos realistas (precios, distancias, tarifas, datos abiertos) del entorno de un instituto español.
Cada problema debe:
- Tener una pregunta clara
- Requerir modelización o interpretación (no solo cálculo mecánico)
- Incluir al menos un dato superfluo o una decisión a justificar
No des las soluciones.
```

### Crear actividad de «error plantado»

```
Genera una resolución aparentemente correcta de este problema de [tema] para [nivel], pero introduce 1-2 errores sutiles (aritmético, de signo, de aplicación de propiedad o de interpretación).
Marca internamente los errores pero no los reveles en el texto que verá el alumno.
Al final, en una sección separada llamada "Errores introducidos", explica cuáles son y por qué.
Problema:
[pegar]
```

## 2. Andamiaje y tutorización

### Tutor socrático (sin dar la solución)

```
Eres un tutor de Matemáticas paciente y socrático para alumnado de [nivel].
El alumno está trabajando este problema:
[pegar problema]
Reglas estrictas:
- Nunca des la solución final ni el resultado numérico.
- Haz solo UNA pregunta o da UNA pista cada vez.
- Adapta el nivel de ayuda según las respuestas del alumno.
- Si el alumno se bloquea, ofrece una pista más concreta, pero sigue sin resolver.
Empieza preguntando qué ha intentado ya.
```

### Pistas graduadas

```
Para el siguiente problema de [tema] de [nivel], genera 4 pistas de dificultad creciente.
La pista 1 debe ser muy general (sobre la estrategia).
La pista 4 puede ser casi la solución, pero sin el resultado final.
Problema:
[pegar]
```

## 3. Diferenciación y accesibilidad (DUA)

### Reformular enunciado

```
Reformula el siguiente enunciado de Matemáticas para 2.º ESO de tres formas:
1. Más simple (vocabulario y frases cortas), manteniendo la demanda cognitiva.
2. Con apoyo visual sugerido (describe qué diagrama o tabla ayudaría).
3. Con contexto más motivador para adolescentes, sin trivializar el contenido.
Enunciado original:
[pegar]
```

### Generar ejemplos y no-ejemplos

```
Para el concepto de [concepto] en [nivel], genera:
- 4 ejemplos claros
- 3 no-ejemplos (casos que parecen pero no cumplen la definición)
- Una pregunta que ayude a discriminar
Usa lenguaje accesible.
```

## 4. Evaluación y feedback

### Borrador de rúbrica

```
Elabora una rúbrica analítica de 4 niveles (Excelente / Adecuado / En desarrollo / Insuficiente) para evaluar [producto o proceso] en Matemáticas de [nivel].
Criterios orientados a: [comprensión / modelización / comunicación / uso de representaciones…].
Cada celda debe describir conductas observables, no adjetivos vagos.
```

### Feedback formativo a partir de una respuesta

```
Actúa como profesor de Matemáticas de [nivel].
A continuación tienes la respuesta de un alumno a este problema:
Problema: [pegar]
Respuesta del alumno: [pegar]
Escribe un feedback formativo breve (máx. 120 palabras) que:
- Señale qué está bien
- Señale el error principal o la laguna
- Dé una pista o pregunta para mejorar (sin dar la solución)
Tono cercano y profesional.
```

## 5. Verificación y pensamiento crítico

### Analizar respuesta de otra IA

```
A continuación tienes una resolución generada por una IA a un problema de Matemáticas de [nivel].
Tu tarea:
1. Indicar si la solución final es correcta o no.
2. Marcar cada paso como: correcto / dudoso / incorrecto.
3. Explicar los errores o imprecisiones.
4. Proponer una versión corregida y más clara.
Resolución:
[pegar]
```

### Generar contraejemplos

```
Para la siguiente afirmación matemática (o «regla» que suelen creer los alumnos), genera 3 contraejemplos claros y explica por qué invalidan la afirmación.
Afirmación:
[pegar]
Nivel: [nivel]
```

## 6. Preparación docente

### Ideas de secuencia

```
Propón una secuencia de 3 sesiones de 50 minutos para introducir [tema] en [nivel] (LOMLOE).
Incluye: objetivo de aprendizaje, actividad principal de cada sesión, posible uso legítimo de IA y evidencia de evaluación formativa.
No generes materiales completos, solo el esqueleto.
```

### Preguntas de profundidad

```
Para el tema [tema] de [nivel], genera 8 preguntas de distintos niveles cognitivos (recordar, aplicar, analizar, evaluar, crear) que puedan usarse en clase o en evaluación.
Indica el nivel cognitivo de cada una.
```

---

*Adapta siempre el nivel, el vocabulario y el currículo. La IA no conoce tu programación de aula ni a tu grupo concreto.*
