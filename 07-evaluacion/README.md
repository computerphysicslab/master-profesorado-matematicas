## Principios de uso (resumen)

1. **No se evalúa un descriptor o una CE porque se haya hecho una actividad**, sino por evidencias de lo que el alumnado demuestra saber hacer.
2. **Alineación:** criterio de evaluación → tarea y andamiaje → evidencias → juicio/calificación trazable.
3. **Formativa antes que sumativa:** la información debe servir para actuar (feed up / feed back / feed forward).
4. **Bajo coste y alta frecuencia** cuando sea posible: tickets, borradores, audio breve, observación estructurada.
5. **El error como información**, no solo como fallo a penalizar (clima y autoeficacia).
