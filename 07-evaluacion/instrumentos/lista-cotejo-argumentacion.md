# Lista de cotejo — argumentación y comunicación matemática

**Tipo:** coevaluación / autoevaluación / observación breve  
**Alineación:** CE.M.7–8 (representar, comunicar, argumentar)  
**Rúbrica asociada:** [rubrica-comunicacion-argumentacion-ce7-ce8.md](../rubricas/rubrica-comunicacion-argumentacion-ce7-ce8.md)

## Uso

Marcar **sí / no / a medias** sobre una producción concreta (pizarra, párrafo, audio, poster). Ideal para revisión entre iguales tras modelar un ejemplo.

**Producción evaluada:** ________  **Autor/a (o anónimo):** ________  **Revisor/a:** ________

| # | Indicador observable | Sí | A medias | No |
|---|----------------------|:--:|:--------:|:--:|
| 1 | Enuncia con claridad **qué** se afirma o se pide | | | |
| 2 | Usa **datos o propiedades** pertinentes (no solo opiniones) | | | |
| 3 | El razonamiento tiene un **orden** comprensible (pasos o estructura) | | | |
| 4 | Emplea **representación** adecuada (álgebra, gráfico, tabla, dibujo…) cuando ayuda | | | |
| 5 | **Justifica** los pasos clave (no solo escribe el resultado) | | | |
| 6 | La conclusión **responde** a la pregunta planteada | | | |
| 7 | El lenguaje es **preciso** (términos matemáticos bien usados o explicados) | | | |
| 8 | (Si aplica) Señala **límites** o posibles errores de la solución | | | |

**Un aspecto fuerte:** …

**Un aspecto a mejorar (concreto):** …

---

## Normas para coevaluación

1. Comentar la **producción**, no a la persona.
2. El «a mejorar» debe ser **accionable** (qué cambiar en la próxima versión).
3. No promediar «por simpatía»: si falta justificación, se marca.
4. El docente modela 1–2 revisiones en voz alta antes de dejar sola al grupo.

---

## Variante mínima (3 ítems)

Para sesiones muy cortas:

1. ¿Se entiende el razonamiento sin preguntar al autor? S/N  
2. ¿Hay justificación de los pasos clave? S/N  
3. ¿La respuesta encaja con el enunciado? S/N
