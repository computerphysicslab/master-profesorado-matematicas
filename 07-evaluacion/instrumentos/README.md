# Instrumentos de evaluación de bajo coste — Matemáticas

Plantillas listas para adaptar en ESO y Bachillerato. Están pensadas para **evaluación formativa frecuente**: generan evidencias sin saturar al docente ni al alumnado.

**Marco:** [Evaluación formativa global](../../02-apuntes/evaluacion/evaluacion-formativa-global.md) · [README de evaluación](../README.md)

## Principios de uso

1. El instrumento **no sustituye** al criterio de evaluación: solo recoge evidencias alineadas con él.
2. Tras usarlo, hace falta **actuar** (agrupar, reexplicar, proponer práctica diferenciada, devolver feedforward).
3. Preferir **pocos ítems claros** a rúbricas largas en cada sesión.
4. Anonimizar ejemplos públicos; no exponer notas individuales en el grupo.
